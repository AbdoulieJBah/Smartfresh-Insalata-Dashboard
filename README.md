# 🥬 SmartFresh AI — Insalata dell’Orto Dashboard

An AI-powered business intelligence dashboard for monitoring production, inventory, waste, quality, expiry risk, and deliveries in fresh produce operations.

## 🚀 Features

- 📊 Executive dashboard (KPIs & insights)
- 🥬 Inventory & expiry monitoring
- ✅ Quality control & defect analysis
- 📦 Orders & delivery tracking
- 🔎 Batch traceability
- 🤖 AI-ready architecture (for future Copilot integration)
-  💬 Supplier Feedback Sentiment Analysis
- ⚠️ Negative Feedback Alerts
- 🏭 Supplier Sentiment Ranking

## 🧠 Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## 📦 Installation

```bash
pip install -r requirements.txt
